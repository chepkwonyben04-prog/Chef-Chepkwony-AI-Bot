# BC's AI 👨🏾‍🍳🤖

An AI-powered culinary assistant by Chef Chepkwony, designed to share cooking knowledge, recipes, and culinary inspiration from Kenya, Africa, and around the world.

## About

BC's AI is the official culinary assistant by Chef Chepkwony.

It helps users discover:

- Kenyan cuisines
- African cuisines
- International cuisines
- Global culinary traditions
- Recipe ideas
- Cooking techniques
- Food knowledge
- Culinary tips
- Recipe explanations

## Features

✅ Chef Chepkwony personality and cooking style  
✅ Recipe knowledge base  
✅ Culinary storytelling  
✅ Cooking guidance  
✅ Expandable AI integration  
✅ Telegram bot support
